# sport

Личный проект «Сильнее и суше»: 12-недельная программа, тренировки и отслеживание прогресса.

## v0.2

- FastAPI + SQLite на VPS.
- Данные синхронизируются между телефоном и компьютером.
- Автоматическая миграция старых данных из localStorage при первом запуске серверной версии.
- Оценка восстановления по сну, энергии, боли и пульсу покоя.
- Журнал силовых результатов и 24 уровня силовых тренировок.
- База для последующего импорта Garmin/Huawei.
- Серверные данные не хранятся в GitHub.

## Развёртывание

На сервере проект ожидается в `/opt/apps/sport`.

```bash
cd /opt/apps/sport
git restore deploy/install.sh
git pull --ff-only origin main
bash deploy/install.sh
```

Важно: не нужно делать `chmod +x deploy/install.sh` перед `git pull`. На некоторых серверах изменение executable-bit считается локальным изменением Git и блокирует последующее обновление.

После установки сервис слушает `127.0.0.1:8911`, а Tailscale Serve публикует его внутри tailnet по `/sport/`.

## Данные

SQLite: `/opt/apps/sport/data/sport.db` — каталог `data/` исключён из Git.
